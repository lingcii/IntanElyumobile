# Mobile & PWA Architecture

The mobile application is designed as a hybrid Progressive Web App (PWA) packaged into a native Android APK using **Capacitor**.

Connected Subsystems: [[offline-sync-engine]], [[itinerary-system]], [[api-and-database]]

---

## Directory & Asset Flow

- `frontend/Mobile/src/`: Source PHP views, JS logic, and styles.
- `frontend/Mobile/public/`: Deployed web root containing assets and bundled scripts.
- `frontend/Mobile/android/`: Native Android project generated by Capacitor.

---

## Asset Synchronization Command

Whenever changes are made to frontend assets:
```powershell
npx cap copy android
```
This syncs `public/` web assets into `android/app/src/main/assets/public/` so APK builds always reflect the latest code.
